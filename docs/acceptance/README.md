### 活动复用与常用资料

日期：2026-10-07。分支：victor。使用隔离本地环境和虚构个人资料验证，未操作共享环境。

### 已验证行为

- 本人的草稿、已发布或已取消活动可复制为新草稿；票种名称、价格和配额保留，已售数量和首次销售标记重置，不复制订单。
- 新草稿可修改时间并发布；发布失败后保留已保存内容。
- 常用资料保存后刷新仍可读取，可清空；无权限读取其他账号的预填资料。
- 预订时手动应用活动所需的常用资料，再改成不同姓名，不影响已保存资料。
- 学生证号、护照号分别配置和填写，自定义问题由发布者命名，答案随订单保存。
- 资料页与预订页显示隐私提示；发布者只通过所属活动订单读取已提交资料。
- 清空个人常用资料后，已有订单快照保持不变。
- 旧版通用证件字段迁移为自定义问题和答案，保留历史内容。

### 报名截止时间

日期：2026-10-07。分支：victor。使用隔离本地环境和虚构账户。

- 草稿可设置、保存并复制报名截止时间；不得晚于开始时间，发布时不得已过期。
- 留空默认活动开始时间；旧活动迁移保持原预订截止行为。
- 公开详情显示报名截止时间；页面停留到截止时自动关闭预订。
- 截止后后端返回409，库存不变；已有订单重试和活动开始前取消仍可正常进行。
- 时间输入显示 `YYYY-MM-DD HH:mm`，精确到分钟，按SGT转换保存；保留日历按钮。
- Chrome区域设置为zh-CN时验证英文输入提示、日历打开和保存流程，均通过。

### 使用边界

普通活动可以留空开始报名时间，发布后直接报名；限额活动按需定时开放。预约仅保存资料，不保留名额、不自动报名、不保证抢票成功。目前支持免费票，没有开售通知、排队或候补递补。BOOKED 表示已关联过订单，订单当前状态以 My orders 为准。并发测试验证库存一致性，不代替生产规模负载测试。
