## 浏览器演示步骤

1. 准备组织者与参与者，管理员授予组织者角色并重新登录。
2. 创建容量2的活动并先发布，再通过票种页面创建配额2的免费票，验证已有已发布活动也能接入。
3. 参与者预订2张，库存售罄；确认订单号和“View my orders”仍保留。
4. 从订单详情取消；组织者订单页显示Cancelled。
5. 参与者重新预订1张，组织者取消活动；组织者列表显示Event cancelled，参与者仍能查看取消订单快照。
6. 另建一笔有效订单，重启数据库、后端和前端，重新登录后核对订单及库存。
