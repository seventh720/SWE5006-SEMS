- `/events`：标题搜索、每页 10 条、上一页/下一页、加载、空结果和失败重试。

## 接口与联调边界

使用现有 `apiRequest`，请求建议的 `GET /api/v1/events` 和 `GET /api/v1/events/{id}`，不使用演示数据。后续后端批次现已实现这两个接口，仅放行公开 GET 请求，草稿和取消活动由数据库查询过滤。重启新版后端后，空库返回空列表；接口不可用时页面显示错误提示。

当前 JSON 使用 camelCase：`id`、`title`、`description`、`location`、`startsAt`、`endsAt`、`capacity`、`status`；日期为含时区 ISO 8601 字符串。列表外层为 `items`、`page`、`size`、`totalElements`、`totalPages`。状态应为 `PUBLISHED`，字段已通过后端响应测试确认。

## 草稿管理批次

- 页面：`/organizer/events`、`/organizer/events/new`、`/organizer/events/:id`。
- 管理端需要组织者或管理员角色；归属由 JWT 确定，管理员没有跨账号代管权限。
- 表单提供长度、整数容量、时间顺序校验；新加坡时间与 ISO 时间双向转换。
- 保存后显示成功反馈；400 字段错误、401/403 重新登录、404 不可访问、409 版本冲突有对应提示。
- 请求携带当前版本，JPA 乐观锁保护并发修改；过期编辑不会覆盖已保存内容。
- 草稿不会出现在公开列表；保存后可通过发布操作公开。

验证：`RUN_CONTAINER_TESTS=true mvn verify`（30 个测试）；前端 `npm run build` 和 `npm test`（19 个测试）。新增前端交互测试覆盖创建、时区提交、冲突保留文字及重载、时间校验、登录过期和角色路由；数据库测试覆盖创建读取编辑、归属隔离、角色权限、非草稿与旧版本冲突，以及两个事务的并发写入。浏览器视觉检查尚未执行。

## 发布与取消批次

- 发布／取消都要求二次确认、本人归属及当前版本；状态更新后刷新管理详情和可用操作。
- 发布只允许未来开始的草稿；发布后禁止编辑。
- 草稿和已发布活动均可取消，取消不可恢复；公开查询不再返回该记录。
- 未保存的修改阻止状态操作；失败保留页面并提示重试或重新加载最新版本。
- 后端 `RUN_CONTAINER_TESTS=true mvn verify`：37 个测试通过，包括生命周期、非法状态、归属权限、过期时间和编辑与状态转换并发冲突。
- 前端 `npm run build`、`npm test`：21 个测试通过，包括操作确认、公开入口、取消后按钮变化、版本传递与未保存修改阻止发布。
- 尚未执行真实浏览器视觉检查；自动化交互使用 jsdom，API 和迁移使用隔离 PostgreSQL。
