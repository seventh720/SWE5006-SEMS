# Sprint 2 页面搭建：第一批

本批仅覆盖 S2-07 活动浏览页面，尚未达到 Sprint 2 完成定义。

- `/events`：标题搜索、每页 10 条、上一页/下一页、加载、空结果和失败重试。
- `/events/:id`：标题、描述、地点、起止时间、容量；时间统一展示新加坡时区。
- 搜索及页码记录在 URL 中，详情返回列表保留查询条件。
- 首页和登录页增加活动浏览入口；前端采用工作安排建议的访客浏览路由。

## 接口与联调边界

使用现有 `apiRequest`，请求建议的 `GET /api/v1/events` 和 `GET /api/v1/events/{id}`，不使用演示数据。后端目前只有活动模块占位，接口不可用时页面会显示错误提示。后续需实现接口并仅放行公开 GET 请求；草稿和取消活动的隔离由后端保证。

本批暂定 JSON 使用 camelCase：`id`、`title`、`description`、`location`、`startsAt`、`endsAt`、`capacity`、`status`；日期为含时区 ISO 8601 字符串。列表外层为 `items`、`page`、`size`、`totalElements`、`totalPages`。状态应为 `PUBLISHED`，后续联调时确认契约。
